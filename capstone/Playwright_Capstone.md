## ENTERPRISE E-COMMERCE AUTOMATION FRAMEWORK
Application Under Test:  https://automationexercise.com/

## PROBLEM STATEMENT

You have joined a client engagement as an Automation QA Engineer. The client owns an online retail platform and wants to establish a scalable, maintainable, and production-ready Playwright automation framework. Your task is to build a test automation solution that validates critical business workflows, demonstrates engineering best practices, and showcases your ability to work in a real project environment. 

## BUSINESS GOALS

Ensure critical customer journeys work reliably across browsers, reduce manual validation effort, provide clear execution reporting, support future framework scalability, and demonstrate modern testing practices including accessibility, visual validation, and AI-assisted testing. 

## PROJECT REQUIREMENTS

Create a Playwright TypeScript framework using Page Object Model, Fixtures, reusable utilities, configuration management, test data separation, reporting, screenshots, traces, and crossbrowser execution. 

## FUNCTIONAL TEST COVERAGE

*   User Registration/Login and Logout
*   Product Search, Add/Remove Products from Cart
*   Checkout Flow
*   Order Placement Validation
*   Contact Us Form Validation

## ADVANCED PLAYWRIGHT REQUIREMENTS

*   Page Object Model (POM) implementation
*   Custom Fixtures
*   Data Driven Testing
*   Network Interception and Mocking
*   Trace Viewer and Debugging
*   Cross Browser Execution

## MODERN TESTING PRACTICES

*   Accessibility Testing using `axe-core`
*   Visual Regression Testing
*   AI Assisted Test Creation with Copilot/MCP

## EXPECTED FRAMEWORKS STRUCTURE

*   pages/
*   fixtures/
* tests/
*   utils/
*  testdata/
*   config/
*   reports/

## FINAL DELIVERABLES

*   Complete Playwright Framework Source Code with Execution reports
*   5-8 Automated Test Cases
*   README Document explaining framework design
*   Short Presentation of framework architecture and decisions

## WHAT IS EXPECTED FROM THE CANDIDATE

*   Candidates should demonstrate the ability to think like an Automation Engineer rather than simply writing scripts. 
*   The framework must be scalable, readable, reusable, and easy for multiple team members to maintain. 
*   Candidates must confidently explain locator strategy, synchronization handling, POM implementation, fixtures, test organization, and reporting. 
*   Candidates should be able to debug failures using Trace Viewer, screenshots, logs, and Playwright tooling. 
*   Candidates should show understanding of network mocking, accessibility validation, visual testing, and cross-browser execution. 
*   Candidates should leverage AI tools responsibly and explain where generated code was improved or optimized. 
*   Candidates should present the solution as if explaining it to a client or interview panel.
